# V1.01（内部版本 1.0.1）

模型页提供两种下载方式：

- **本地下载（原方式）**：默认选项，沿用已有的本站/GitHub Pages、Hugging Face 和镜像来源；不会把阿里云作为自动回退来源。
- **阿里云下载**：在网页里验证管理员提供的邀请码后启用。模型仍在当前设备运行。当前发布的五个模型包使用武汉 OSS 中的 `models/` 和 `voice-models/` 文件，网页程序及运行组件仍由网站提供。

邀请码仅限制网页入口。OSS 文件继续允许匿名 HTTPS 读取，知道地址的人仍可直接下载；这不是身份认证、流量限额或费用硬上限。不要将 AccessKey 写进网页。公开配置仅存邀请码的 SHA-256；验证结果保存在当前浏览器。清除浏览器数据后需要重新验证。

管理员当前邀请码保存在本地、被 Git 忽略的 `build/download-invitation.txt`。只发给获准的人。需要换码时运行：

```console
python tools/set_download_invitation.py --generate
```

发布更新后的 `app/packs.json` 后，旧的网页批准记录失效。已经下载的模型和旧 OSS 直接链接不会被撤销。下载中不能切换来源；切换后保留已有的语音缓存，WebLLM 保留下载时的地址以复用自己的缓存。

手机页头和“我”页展示 V1.01。背单词答题后可查看同族词、衍生词及词形变化，数据依据固定版本的 CET 词表和 ECDICT，生成脚本为 `tools/prepare_word_relations.py`。关联词不自动获得当前考试词库标签，考试词库范围没有改动。

增加“只练有配图的单词”，按当前词库、主题和场景筛选已配图的词。当前图片仍覆盖 614 个词，没有给整本词库补齐图片。该选项默认关闭；开启时会说明它不代表完整考试范围。图片使用完整显示方式，避免裁掉画面。

验证包括：邀请码拒绝/通过/保留、原方式不访问 OSS、阿里云模型及语音地址、下载中禁止切换、识别缓存跨来源复用、手机版本和布局、配图筛选、答题前不泄露衍生词答案。OSS 116 个文件通过大小及 CORS 检查，另取四个 64 字节 Range 样本与本地核对；没有重新下载整套模型验证全量远端哈希。浏览器测试不等同于真实 iPhone 测试。
